# Profile-driven Live2D 데스크톱 펫

기본 실행은 투명 배경·테두리 없는 데스크톱 펫이다. 기존 Python/PySide6 `QOpenGLWidget`과 live2d-py 모델 로딩·표정·물리·수면을 재사용한다. 일반 창 실험실은 `--lab`으로 유지한다.

공통 엔진은 모델별 파일명과 parameter ID 대신 `profiles/*.json`의 semantic mapping을 사용한다. 현재 火花, 椿, IceGirl 세 프로필이 있으며, valid profile을 추가하면 우클릭 `캐릭터` 메뉴에 자동 표시된다. 선택한 캐릭터는 저장 후 안전하게 재시작되며 다음 실행에도 유지된다. 신규 모델 분석과 profile 작성 절차는 [MODEL_PROFILES.md](MODEL_PROFILES.md)에 있다.

## 데스크톱 펫 조작

쓰다듬기 입력 경로를 수정했다. 기존 Windows 저해상도 타이머 때문에 왕복 기록이 지워지던 문제를 재현하고 고쳤다. 현재 실제 Qt 마우스 이벤트 경로·240/400px 크기·드래그/수면 구분 검사까지 통과했다. 원인과 검증 범위는 [PETTING_FIX.md](PETTING_FIX.md)에 정리했다. 사람 손의 감도 검증은 별도다.

- 왼쪽 버튼으로 캐릭터를 끌어 이동한다. 사용자가 마지막으로 놓은 위치와 크기는 다음 실행 때 복원되며, 자율 재배치 위치는 저장 위치를 덮어쓰지 않는다.
- 버튼을 누르지 않고 이마·머리 부근을 3회 이상 부드럽게 왕복하면 눈 감김·홍조·고개 반응이 나타난다. 단발 통과나 정지, 드래그는 쓰다듬기로 처리하지 않는다.
- 우클릭 메뉴: 캐릭터 전환, 자율 이동 켜기/끄기, 가로 슬라이더로 크기 180~3000px 조절, 수면 시작/해제, 개발용 제어판, 종료. 수면 모션이 없는 椿에서는 수면 항목이 비활성화된다.
- 최초 크기는 캐릭터 높이 약 300 논리 픽셀. 장식과 머리카락 주변 여백을 확보한다.
- 데스크톱 투명 render window는 기존 렌더 영역의 가로·세로 2배이며, 캐릭터 크기와 중심은 유지하고 둘레를 투명 여백으로 사용한다. 드래그·복원·자율 재배치의 화면 경계는 framebuffer에서 캐시한 실제 캐릭터 실루엣을 기준으로 계산하며, 프로필 기본값으로 실루엣 높이의 65%까지 화면 아래 배치를 허용한다.
- 큰 크기에서도 캐릭터 렌더 영역은 화면에 맞춰 축소하지 않는다. 투명 여백은 방향당 최대 512px로 제한하고, 2백만 물리 픽셀을 넘는 입력 마스크는 작은 크기에서 얻은 실루엣을 확대해 사용하여 대용량 framebuffer readback을 피한다.
- 자율 이동은 보통 20~60초 쉬고 0.35~0.45초 fade out한 뒤 현재 모니터의 먼 위치로 투명 상태에서 재배치하고 0.45~0.55초 fade in한다. 자세한 구조와 검증은 [RELOCATION.md](RELOCATION.md)에 있다.
- 평상시에는 10~25초 간격으로 65% 확률의 가벼운 표정을 8~12초 보여준다. 의미 있는 상호작용이 60~90초 없으면 major idle 시점에 삐짐/약한 화남 또는 기존 수면 모션을 50:50으로 선택한다. 별도의 180초 자동 수면 타이머는 없다. 자세한 설정과 검증은 [IDLE_REACTIONS.md](IDLE_REACTIONS.md)에 있다.
- 드래그·쓰다듬기·메뉴·제어판·수면 중에는 이동을 멈춘다. 상호작용 종료 후 다시 20~60초 기다린다. 수면 중 쓰다듬기는 꺼진다.
- 투명한 빈 공간은 아래 앱으로 입력을 넘기고 캐릭터는 조작 가능하다. 가장자리에는 4px의 입력 여유가 있다.
- 항상 위에 표시하지만 일반 조작은 키보드 포커스를 가져오지 않는다. 개발용 제어판을 명시적으로 열 때는 입력을 위해 활성화한다.
- 종료는 캐릭터 우클릭, 트레이 분홍 아이콘 우클릭, 작업 표시줄 창 닫기로 가능하다. 트레이에는 화면 안으로 불러오기도 있다.

동작·프로필·입력 처리·검증 상세는 [PET_GUIDE.md](PET_GUIDE.md)에 기록했다. 원본 ZIP·모델·워터마크는 이번 펫 구현에서 변경하지 않았다.

## 두 번째 모델 椿 — 2026-09-11

`11月椿.zip`은 UTF-8 filename flag 없이 GBK 메타데이터를 사용한다. 준비 단계는 CP437 상자문자 형태의 깨짐이 명확할 때만 GBK/CP932 후보를 비교하며, 일반 UTF-8·ASCII ZIP은 기존 경로를 유지한다. 원본 SHA-256은 `4324b6eed3cf36d007c8c9fe27a418f36a5a8e2c2658b4cebd96f2959bca4a1e`이다.

椿 프로필은 실제 moc3의 110개 파라미터와 표정 5개를 읽어 눈, 시선, 입, 고개, 몸, 호흡, 홍조와 하트 눈을 연결한다. 모델에 HitArea가 없어 실제 framebuffer와 MVP를 기준으로 머리 영역 `[-0.17, 0.58, 0.17, 0.96]`을 사용한다. 배율 `0.74`, 창 비율 `0.82`, 높이 계수 `1.43`에서 기본 캐릭터 높이는 약 287 논리 픽셀이며 장식과 머리카락이 잘리지 않는다.

별도 수면 모션은 없다. 유일한 `motions/idle.motion3.json`은 눈물 파라미터용 반복 효과이므로 수면에 매핑하지 않았다. 따라서 major idle에서는 sleep 후보가 자동 제거되고 persistent NEGATIVE만 남으며, 메뉴 수면 항목도 비활성화된다. 실제 AMD Radeon 840M/OpenGL 4.6 환경에서 투명 렌더링, 클릭 통과, 드래그, 저장, 화면 복귀, 프로필 메뉴, fade 재배치, 오탐 방지, 머리 쓰다듬기, positive 복귀, ambient, persistent NEGATIVE, NEGATIVE 중 이동 차단, direct positive 회복과 no-sleep fallback을 통과했다.

표정 파일의 이름·parameter와 실제 정지 렌더를 함께 확인해 ambient=`眼高光消失`, negative=`黑脸`/`哭`, positive=`脸红`+`爱心眼`으로 매핑했다. 작은 데스크톱 크기에서 감정이 자연스럽게 읽히는지와 실제 손 움직임의 머리 영역 감도는 사용자 확인을 권장한다. 실제 restart 경로에서 火花→椿과 椿→火花를 각각 수행했고, 창이 한 개만 남는 것과 `(1381, 676)`, 높이 `240`의 저장값 유지, 椿 선택 후 무인자 재실행 복원도 확인했다.

## 세 번째 모델 IceGirl — 2026-09-11

`IceGirl_Live2d.zip`의 실제 파일과 동봉된 JSON dump를 함께 조사해 표정 20개, 모션 3개와 표준 눈·시선·입·고개·호흡 파라미터를 inventory했다. 실제 ZIP의 텍스처는 사전 설명과 달리 8192 한 장과 4096 세 장이다. 원본은 그대로 보존하고 공통 준비 정책이 4096을 넘는 런타임 텍스처만 비율·alpha를 유지해 축소한다. 따라서 IceGirl 런타임은 4096 RGBA 네 장이며 model3 참조는 ASCII runtime 파일로 연결된다.

실제 framebuffer와 MVP를 기준으로 배율 `0.74`, 창 비율 `0.90`, 머리 영역 `[-0.13, 0.34, 0.13, 0.64]`를 정했다. 기본 실루엣 높이는 약 284 논리 픽셀이다. ambient=`疑惑`, negative=`生气`(가중치 3)/`脸黑`(가중치 1), positive=`脸红`+`爱心眼`으로 연결했다. 수면 모션은 없어 메뉴와 major idle의 sleep 후보가 자동으로 빠진다. 세 motion은 inventory와 개발 패널에는 포함하지만 새 행동으로 연결하지 않았다.

## 기존 실험실·개발용 제어판

전체 일반 창 실험실은 `app.py --lab`으로 실행한다. 펫 우클릭의 개발용 제어판은 같은 모델을 제어하는 별도 숫자 패널이다. 패널을 닫아도 펫은 유지된다. 펫 크기는 우클릭 메뉴로 변경하며 패널의 확대 슬라이더는 비활성화된다.

- **눈·시선·입·고개·호흡**: 오른쪽 숫자 입력/화살표로 조절한다. 범위와 기본값은 `.moc3`를 로드한 실제 런타임의 `GetParameter()`에서 읽는다. 툴팁에 ID와 범위가 표시된다. 눈 수동 조절은 자동 깜빡임, 시선 수동 조절은 마우스 추적, 호흡 수동 조절은 자동 호흡을 끈다.
- **시선 추적**: 체크 후 모델 영역에서 마우스를 움직인다. 추적은 모델 영역 안에서만 작동한다.
- **표정**: 기본 표정 및 현재 프로필의 원래 파일명으로 표시한 표정 중 하나를 선택한다. 모델에 포함된 워터마크 등도 그대로 표시된다.
- **수면**: 4초짜리 원본 모션은 `Loop: true`이므로 중지할 때까지 반복된다. 재생 시 이전 표정을 해제한다. 수면 중에는 자동 깜빡임·호흡·시선·수동 얼굴 입력을 적용하지 않는다.
- **중지 · 정상 대기로 초기화**: 모션과 표정을 중지하고 모든 런타임 파라미터와 수동 제어값을 모델 기본값으로 돌린다. 사용자가 체크해 둔 자동 동작은 다시 작동한다. 이전 표정이나 고개 각도로 되돌리는 방식이 아니다.
- 창 크기 및 하단 확대 슬라이더를 조절할 수 있다.

`循环动画`는 일반 대기로 재생하지 않는다. 별도 `Effects` 그룹에 로드만 한다. 따라서 눈물·어지러움·화남 표정은 표시되지만 해당 반복 효과 모션의 애니메이션은 이번 UI에서 재생하지 않는다.

## 모델 보존과 소스 배포

`prepare_model.py`는 ZIP을 읽기 전용으로 열고 SHA-256별 `models/<hash>/original/`에 압축을 푼다. ZIP 경로 이탈을 검사한다. `original` 파일은 수정하지 않는다. `runtime/`에는 네이티브 로더용 ASCII 파일명 사본을 만들며 **사본의** 모델 설정에서 파일 참조 경로만 바꾼다. 원본 모델 설정은 변경하지 않는다.

model3가 참조한 텍스처만 런타임 사본으로 복사한다. 4096을 넘는 텍스처는 원본을 건드리지 않고 runtime 사본만 4096 이내로 축소하며 manifest에 원본/런타임 크기를 기록한다. 미참조 파일도 original 추출본에는 보존된다. 각 모델의 별도 표정과 모션은 `LoadExtraExpression`, `LoadExtraMotion`으로 별도 로딩한다. `assets.json`은 runtime 파일과 원본 상대 경로를 연결하는 inventory다. 캐릭터 선택은 `--profile <id>` 또는 우클릭 캐릭터 메뉴를 사용하며, valid profile이 없는 모델은 펫으로 실행하지 않는다.

`models/`, `.venv/`, `artifacts/`, 조사용 `research/`, ZIP 및 Live2D 확장자를 `.gitignore`로 제외했다. 화면 캡처에도 모델이 포함되므로 `artifacts`를 제외한다. `.gitattributes`에도 로컬 폴더를 `export-ignore`로 지정했다. 이 작업은 Git 저장소를 새로 초기화하거나 커밋하지 않는다.

소스 전달이 필요할 때는 폴더 전체를 압축하지 말고 아래 명령을 사용한다. 명시적인 소스·profile·문서·검증 파일만 포함하므로 모델·캡처·가상환경이 배포 ZIP에 들어가지 않는다. 설치 파일 제작은 이번 범위에 포함하지 않았다.

```powershell
.\.venv\Scripts\python.exe export_source.py
```

## 구현

`initializeGL()`에서 `glInit` 및 모델·텍스처·추가 에셋 로딩, `resizeGL()`에서 모델 비율 조정, `paintGL()`에서 입력값 적용 → `Update()` → `Draw()`를 실행한다. 디바이스 배율을 반영한 물리 픽셀 viewport로 렌더링한다. Qt 타이머는 33ms 간격(약 30fps)으로 갱신을 요청하며 실제 FPS는 환경에 따라 달라진다.

고정한 live2d-py의 `LAppModel.Update()`가 네이티브 모델 업데이트를 호출하며 모션·표정·물리·포즈·메시를 처리한다. 앱에서 물리를 다시 호출하지 않는다. 내장 자동 눈/호흡은 꺼 두고 앱이 런타임 범위에 맞춰 눈 깜빡임과 `ParamBreath`만 생성한다. 따라서 수동 고개 회전을 내장 호흡이 덮어쓰지 않는다. LipSync 그룹이 비어 있어도 `ParamMouthOpenY`를 직접 제어할 수 있다.

표정은 이전 큐를 비우고, 모든 표정이 참조하는 파라미터 집합을 기본값으로 복구한 뒤 새 표정을 적용한다. 대기 프레임에서도 이 기준값을 유지하므로 `Add 0` 잔류나 누적을 방지한다. 수면 중에는 이 대기용 복구도 멈춘다. 창 종료와 컨텍스트 파괴 시 GL 컨텍스트가 활성화된 상태에서 renderer를 해제하고 마지막에 Cubism을 종료한다.

## 아직 확인하지 못한 부분

다른 GPU/드라이버, 원격 데스크톱, 여러 모니터 사이 DPI 전환, 장시간 메모리 안정성은 검증하지 않았다. 물리 입력/출력 반응은 검사하지만 원 제작 프로그램과의 픽셀 단위 물리·표정 일치까지 보장하지 않는다. 추가 효과 모션은 로딩만 확인했다. 카메라 이동/컨텍스트 재생성에 따른 모델 상태 보존은 후속 개선 대상이다. 밥주기, 친밀도, AI 대화, 음성, 별도 대형 모델 선택 화면 및 설치 파일은 구현하지 않았다.
